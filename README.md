### Stagger

**The agent picks the rungs. You sign.**

Stagger reads a Uniswap v3 pool on Robinhood Chain live, measures how the price moves, and proposes a liquidity ladder: shape (Spot, Curve or Bid-Ask), range and 1–40 bins, with every number explained. One transaction from your wallet; the ladder stays yours.
